Danh sách người dùng

Đọc từ handi_users_v1 — chia sẻ chung với app học viên. Bạn có thể đổi role hoặc xoá tài khoản.

① Import lessons từ index.html

Tự động đọc mảng LESSONS có sẵn trong index.html và nạp vào CMS.

② Xuất bản — Tải index.html đã vá

File sinh ra có sẵn lessons mới nhất + logic đọc từ CMS. Sau khi upload đè GitHub, mọi thay đổi sẽ xuất hiện ngay trong app cùng trình duyệt.

③ Backup / Restore JSON

Xuất toàn bộ lessons ra file JSON để backup, hoặc import file JSON có sẵn.

④ Copy mảng LESSONS thủ công

Nếu bạn muốn tự paste vào index.html.

const LESSONS = [];

① Upload từ máy ⭐ Khuyến nghị

Ảnh sẽ nhúng trực tiếp vào file HTML (base64) — hoạt động offline, không cần host. Dùng ảnh < 200KB để file không quá nặng.

② Imgur miễn phí, không cần đăng nhập

  1. Bấm "Mở Imgur" bên dưới
  2. Kéo thả ảnh vào trang → đợi upload xong
  3. Chuột phải ảnh → "Copy image address" (URL dạng https://i.imgur.com/xxxx.jpg)
  4. Quay lại đây → dán URL vào ô bên dưới
